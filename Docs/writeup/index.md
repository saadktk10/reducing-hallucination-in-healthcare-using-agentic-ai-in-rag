# Write-up

Study digests the paper is written from, one file per section. Created in Phase 10.

Every bullet follows this format:

```
- <statement> : <value> [95% CI] (n=<n>, `results/...`) [meaning: <same thing in simplest words>]
```

| Section | Page |
| --- | --- |
| Abstract | [00-abstract](00-abstract.md) |
| Introduction | [01-introduction](01-introduction.md) |
| Related Work | [02-related-work](02-related-work.md) |
| Methodology | [03-methodology](03-methodology.md) |
| Results | [04-results](04-results.md) |
| Discussion | [05-discussion](05-discussion.md) |
| Conclusion | [06-conclusion](06-conclusion.md) |

### How to use

1. Read the digest for each section.
2. Explain each bullet without looking at the source.
3. Write in your own words.
4. Keep numbers exact (values, CIs, sample sizes).
5. Write the abstract last.
