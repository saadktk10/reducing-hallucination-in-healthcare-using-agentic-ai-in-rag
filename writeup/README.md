# Write-up

Study digests the paper is written from, one file per paper section (Phase 10).

## How to use

1. Read the digest for each section.
2. For each bullet, explain it in your own words without looking.
3. Write your section using your explanations.
4. Keep all numbers exact: values, confidence intervals, sample sizes.
5. Write the abstract last, after all other sections are complete.

## Bullet format

Every bullet in the digest follows:

```
- <statement> : <value> [95% CI] (n=<n>, `results/...`) [meaning: <same thing in simplest words>]
```
